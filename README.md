# Open Model Cheatsheet

> Version v1.25 · Data as of 2026-10-20 · Covers 92 models with verifiable sources

A daily-updated, evidence-annotated selection guide for **open-weight models** — what each model is good at, how it scores, how big it is, and whether you can run it locally.

Most "awesome LLM" lists go stale in a week. This one is maintained like a living document: every morning it is re-checked against the last 24 hours of releases, Hugging Face trending, and benchmark movements — only what changed gets updated.

📖 **Read the full cheatsheet: [open-model-cheatsheet.en.md](open-model-cheatsheet.en.md)**

## How to use this cheatsheet

1. **Start with Quick picks by scenario** — the fastest path: tell it your scenario (agentic coding, local deployment, edge/mobile, long context, multimodal, TTS/ASR, video/image generation…), get a first choice and backups.
2. **Drill into a category table** — each model row carries: license, strengths, key benchmark scores, size, and local-deployment notes.
3. **Check the appendices** — benchmark landscape, today's Hugging Face trending snapshot, watchlist (not yet listed), license risk notes, and a local-deployment friendliness ranking.

## How to read the scores

Every performance number is tagged with its provenance:

- **(official)** — vendor-reported. Treat as the optimistic bound.
- **(third-party)** — independent benchmarks or media (Artificial Analysis, LMArena, etc.).
- **unverified** — conflicting or unconfirmed information. Verify before citing.

Scope note: this covers 92 representative models/versions with verifiable sources — not an exhaustive catalog of every model on earth. Models are added and corrected on a rolling basis.

## Update cadence

Updated **daily** (morning, Asia/Shanghai). The changelog at the bottom of the cheatsheet records every version. If a model you care about is missing or a number looks wrong, open an issue — corrections with a source link are the fastest way to get listed.
