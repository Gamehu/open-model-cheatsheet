## VIII. Decision models (typed-decision, emerging paradigm)

Jev (closed, integrated into the Vercel AI Gateway on 2026-09-16, followed by Cloudflare and LangSmith) popularized typed-decision as a new category: a large share of enterprise model calls need only one executable judgment (tool routing, ticket triage, content moderation, agent guardrails), not full text generation; Laya is its open implementation (dubbed the "open-source Jev") and topped the Hugging Face trending chart. Suited to millisecond, high-frequency decision scenarios; not suited to general chat or complex reasoning.

On 9-28/29 this paradigm spread rapidly: JEV-27B (AutoTrust AI, a 27B self-hosted "System 1 + System 2" unified model) and Intern-Decision (InternLM, a 0.8B/2B/4B multimodal structured-decision family) joined; Julia-1 has been verified against its official model card and listed. On 10-01 Cloudflare released its first open models Clef / Clef-flash (Apache 2.0, Jev API compatible), spreading the paradigm further. The `/v1/systemone` typed-decision API shipped with llama.cpp v0.6.0, supporting laya, julia-1, lev, openjev (including vision), kev, nimble, and Clef. Kev-4B was released personally by Jared Palmer (HF `jaredpalmer/kev-4b`, source repo `q-qp-p/kev`, Apache 2.0); lev was released by InterfazeAI (HF `interfaze-ai/lev`, GitHub `InterfazeAI/lev` with an Apache-2.0 LICENSE); neither gets a standalone row yet. The relationship between OpenJev (openjev org, CC BY-NC 4.0) and autotrust/JEV-27B is unverified; monitoring continues.
